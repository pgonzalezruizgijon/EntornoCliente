1. Eventos con addEventListener

Un evento es una acción que ocurre en la página: hacer click, escribir, cambiar un select, entrar en un input, salir de un input, etc.

Estructura clave: elemento.addEventListener("evento", funcion);
El evento se escribe sin on. Es click, no onclick. 
addEventListener("load", iniciar);

function iniciar() {
  let boton = document.querySelector("#btn");
  boton.addEventListener("click", saludar);
}

function saludar() {
  alert("Hola");
}

Errores típicos

// MAL
boton.addEventListener("onclick", saludar);
boton.addEventListener("click", saludar());

// BIEN
boton.addEventListener("click", saludar);

2. Rescatar datos de formularios

Input, textarea, date, email, number

Se usa .value.

let nombre = document.querySelector("#nombre").value;

Checkbox

Se usa .checked. Devuelve true o false.

let aceptado = document.querySelector("#acepto").checked;

Radio button

Se recorren los radios con el mismo name.

let radios = document.getElementsByName("sexo");
for (let i = 0; i < radios.length; i++) {
  if (radios[i].checked) {
    console.log(radios[i].value);
  }
}

Select

Para el valor se usa .value. Para el texto visible se usa options[selectedIndex].text.

let select = document.querySelector("#color");
let valor = select.value;
let texto = select.options[select.selectedIndex].text;

3. Validaciones HTML5 y setCustomValidity

Validaciones rápidas con HTML5

<input type="email" required>
<input type="text" minlength="3" maxlength="8" required>
<input type="number" min="0" max="10">
<input type="date" min="2026-01-01" max="2026-12-31">
<input type="text" pattern="[0-9]{5}" title="Debe tener 5 números">
pattern usa expresiones regulares. Ejemplo: [0-9]{5} significa exactamente 5 números.

Validación personalizada

Se usa cuando necesitas una condición que HTML no puede comprobar solo, por ejemplo repetir contraseña.

if (password1 === password2) {
  campoPassword2.setCustomValidity("");
} else {
  campoPassword2.setCustomValidity("Las contraseñas no coinciden");
}

Mostrar fecha en formato dd/mm/yyyy

function formatearFecha(fecha) {
  let f = new Date(fecha);
  let dia = f.getDate();
  let mes = f.getMonth() + 1;
  let anio = f.getFullYear();
  return `${dia}/${mes}/${anio}`;
}

Calcular edad

function calcularEdad(fechaNacimiento) {
  let hoy = new Date();
  let nacimiento = new Date(fechaNacimiento);
  let edad = hoy.getFullYear() - nacimiento.getFullYear();

  if (
    hoy.getMonth() < nacimiento.getMonth() ||
    (hoy.getMonth() === nacimiento.getMonth() && hoy.getDate() < nacimiento.getDate())
  ) {
    edad--;
  }

  return edad;
}

Objetivo: comprobar que las dos contraseñas son iguales antes de enviar.

7. Expresiones regulares (REGEX) + métodos JS

Se usan para validar textos (emails, códigos postales, contraseñas, etc.) y para buscar o modificar cadenas.

Métodos importantes


// search → devuelve posición o -1
let texto = "Código 41710";
texto.search(/\d{5}/);

// replace → sustituye coincidencias
texto.replace(/\d{5}/g, "CP");

// split → divide texto
let frase = "hola,adios.mañana";
frase.split(/[,.]/);

// match → devuelve coincidencias
let numeros = "10 20 30";
numeros.match(/\d+/g);
Ejemplo típico: buscar códigos postales con /\b\d{5}\b/

Patrones típicos de examen


// Código postal (5 números)
/^[0-9]{5}$/

// Email simple
/\w+@\w+\.\w+/

// Fecha dd/mm/yyyy
/(\d{1,2}\/\d{1,2}\/\d{4})/

// Solo números
/^[0-9]+$/

// Contraseña fuerte
/^(?=.*\d)(?=.*[a-z])(?=.*[A-Z]).{8,15}$/
