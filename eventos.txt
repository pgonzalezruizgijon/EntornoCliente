div.addEventListener("mouseover", () => {
  div.style.backgroundColor = "yellow";

div.addEventListener("mouseout", () => {
  div.style.backgroundColor = "white";
});

⚙️ 3. LAS 3 FORMAS DE AÑADIR EVENTOS (CLÁSICO EXAMEN)
❌ 1. En HTML
<button onclick="saludar()">Click</button>

👉 Fácil pero poco profesional

⚠️ 2. Propiedad JS
boton.onclick = saludar;
✅ 3. addEventListener (LA BUENA)
boton.addEventListener("click", saludar);

👉 ESTA ES LA CORRECTA 💥

🧠 4. EVENTOS AVANZADOS (MUY PRO)
🎯 Saber qué elemento lanzó el evento
function manejarEvento(e) {
  console.log(e.target); // elemento
  console.log(e.type);   // tipo evento
}

👉 Esto es nivel examen bueno

🖱️ Obtener posición del ratón
document.addEventListener("mousemove", (e) => {
  console.log(e.clientX, e.clientY);
});
🔥 Un solo manejador para varios elementos
function evento(e) {
  alert(`Elemento: ${e.target.id}`);
}

btn1.addEventListener("click", evento);
btn2.addEventListener("click", evento);

👉 Muy típico de pregunta teórica
